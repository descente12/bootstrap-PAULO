# Portfólio Profissional com Bootstrap

Projeto de portfólio responsivo feito com HTML, CSS, JavaScript e Bootstrap 5.

## Como abrir
1. Extraia o ZIP.
2. Abra a pasta `portfolio_bootstrap` no Visual Studio Code.
3. Abra o arquivo `index.html` no navegador (ou use a extensão Live Server).

## Personalizações obrigatórias antes de entregar
Pesquise no `index.html` e substitua:
- `SEU NOME` pelo seu nome completo.
- `SEU-USUARIO` pelo seu usuário do GitHub.
- `SEU-PERFIL` pelo endereço do seu LinkedIn.
- `SEUEMAIL@exemplo.com` pelo seu e-mail.
- `Sua cidade – Brasil` pela sua cidade.
- `SN` pelas iniciais do seu nome (ou substitua pelo caminho de uma foto sua).

Revise os três projetos e os links do GitHub para que correspondam aos trabalhos que você realmente deseja apresentar.

## Publicar no GitHub
No terminal do VS Code, dentro da pasta do projeto:

```bash
git init
git add .
git commit -m "feat: cria meu portfolio profissional"
git branch -M main
git remote add origin https://github.com/SEU-USUARIO/meu-portfolio-bootstrap.git
git push -u origin main
```

Crie antes um repositório público vazio no GitHub com o nome `meu-portfolio-bootstrap` e substitua `SEU-USUARIO`.

## Publicar na Vercel
1. Entre em https://vercel.com com sua conta GitHub.
2. Clique em **Add New → Project**.
3. Importe o repositório `meu-portfolio-bootstrap`.
4. Mantenha as configurações padrão para site estático e clique em **Deploy**.
5. Copie o endereço público gerado pela Vercel.

## Entrega
Envie ao professor os dois links: repositório público do GitHub e site publicado na Vercel.
